# 群聊洞察 · 本地 Web 工作台

启动后访问 http://127.0.0.1:8777 。原项目没有 Web UI，这个本地部署补充了中文界面与本地任务管理。

本地版 1.2 提供笔记采集、评论及回复管理、作者作品采集、媒体下载和定时检查，侧栏可切换：

- 群记录工作台：http://127.0.0.1:8777/
- 笔记采集：http://127.0.0.1:8777/notes
- 评论管理：http://127.0.0.1:8777/comments

## 笔记与评论

与群记录共用本机扫码凭据。关键词搜索支持综合、最新、热门排序，最多保存 40 篇搜索摘要；在列表中选取笔记采集完整正文，或粘贴完整笔记链接、分享文案、xhslink.com 短链接。链接缺少访问参数且本地没有对应搜索记录时，需要重新搜索或复制完整分享链接。

采集详情时可选择仅正文，或最多 20/100/500 条一级评论，并选择是否采集二级回复。回复总量单独设置为最多 20/100/500 条，限定在本轮选取的一级评论下。评论按编号合并；再次刷新不会删除过去记录，页面分别标明一级评论和回复的完成范围。评论管理可筛选全部、仅一级评论或仅二级回复，回复带有原一级评论上下文。

搜索支持全部、图文和视频筛选。“按作者主页采集”接受主页链接或作者 ID，保存最多 40 篇作品摘要；已采集详情的笔记也可通过详情中的“采集该作者作品”进入。

在笔记详情点击“下载图片 / 视频”，完成后可预览或下载单个本地文件。当前每篇最多 30 个媒体文件，单张图片最多 64 MiB、单个视频最多 512 MiB。下载失败时保留已完成文件，可稍后重试；不承诺平台所有视频编码都能在浏览器中播放。

单篇评论页可开启定时检查，最短 5 分钟，最多同时开启 10 篇。按当前评论/回复上限采集；任务串行，失败或取消后自动暂停。修改间隔或数量后点击“保存设置”；已执行的任务沿用启动时的设置。停止监测不取消当前采集，可用任务区的取消按钮。服务重启或重新扫码时暂停监测，保留设置供手动恢复。监测采用分页轮询，不保证实时或完整覆盖大量新增评论。

笔记、评论可本地搜索和分页，CSV/JSON 导出遵循当前搜索及笔记筛选条件。账号 Cookie、访问参数不进入导出。笔记原文链接使用公开地址；平台要求访问参数时请使用原分享链接。

采集任务与群记录串行执行，可取消；连接失败或平台限制会停止任务。后台使用固定版本 MediaCrawler 的 HTTP 客户端，不启动浏览器。上游许可要求见 THIRD_PARTY_NOTICES.md。

首次安装笔记功能运行 `Install-Notes.ps1`，需要 Git、uv。脚本创建独立源码和 Python 环境，固定到 68d9ef1c1da22eab75940dfd7cec259907006538，使用其 uv.lock 安装依赖。可用 `-SourceRepository` 指定已有本地 MediaCrawler 仓库，仅读取已提交源码，不复制其本地账号配置。安装后重启服务。

## 使用

1. 点击“生成登录二维码”，用自己的小红书 App 扫码并确认。
2. 填写有权访问的群会话链接或数字群 ID，可添加群备注。
3. 点击“首次采集”。完成后在“群记录”中搜索、查看消息，导出 JSON 或 CSV。
4. “获取新增消息”补充最近消息；“继续历史采集”补齐更早记录。
5. 如需持续更新，选中已采集的群，设置间隔并开启“定时获取新增消息”。最短五分钟，错误后自动暂停。关闭网页不停止后台服务，停止后台服务或重启电脑后需重新启动并手动开启定时任务。
6. “生成分析”调用原项目的离线消息整理与关键词主题统计，支持下载话题表、互动表和讨论线索，不调用付费大模型。

登录失效时重新扫码。服务不会主动发送私信或群消息；本机保存凭据不代表账号始终有效。

## Windows 启停

在本目录打开 PowerShell：

```powershell
.\Start-WebUI.ps1
.\Stop-WebUI.ps1
```

启动脚本在后台运行，绑定 127.0.0.1，不打开桌面浏览器或窗口。如 8777 被占用，可使用 `Start-WebUI.ps1 -Port 8778`。

首次安装或重建运行环境：

```powershell
.\Install-Local.ps1
```

要求 Python 3.11、Node.js 20+、Git。运行环境位于本工作区 `work/xhs-local-data/runtime/Spider_XHS`。本次部署固定 Spider_XHS 为 `23dab803a0465e35e01cf87137353a900b47e93d`（2026-10-22），补充 cryptography 和 tzdata，并修正 Windows npm.CMD 调用。

## 数据位置

程序代码在当前项目目录。数据与凭据另存于当前工作区的 `work/xhs-local-data/`：

- `auth/`：Cookie 与临时登录二维码，网页不提供 Cookie 下载。
- `exports/<群ID>/`：原始 JSON、CSV 和历史进度。
- `derived/<群ID>/`：整理后的消息与来源摘要。
- `analysis/<群ID>/`：话题、参与情况、讨论线索。
- `preferences.json`：群备注、定时更新设置和最后一次登录结果，不含 Cookie。
- `notes/notes.sqlite3`：笔记、评论和内部访问参数；不要把数据库当作脱敏导出分享。可使用页面上的 CSV/JSON 导出。
- `notes/media/xhs/media/<笔记ID>/`：已完成的图片和视频文件；临时下载片段不会出现在页面中。
- `backups/`：升级前创建的数据库备份，属于本地私有数据。
- `runtime/MediaCrawler/`：固定版本采集源码及独立 Python 环境，含上游 LICENSE。

如需移动工作区，可通过环境变量 `XHS_LOCAL_DATA` 为服务指定数据目录；启停脚本默认使用工作区内的上述路径。

## 本地修改

- 添加 FastAPI 与原生 HTML/CSS/JavaScript 界面，无外部 CDN 或字体。
- 本地页面会话校验、Host/Origin 限制、下载路径检查；Cookie 不进入 API 响应、页面或任务日志。
- 采集任务串行执行，支持取消、超时和失败暂停。
- 登录过程显示扫码、手机确认、网页登录校验和保存阶段；失败时保留脱敏诊断及提示，刷新或重启后仍可查看。
- 增量页数不足时不写入结果，保留旧记录，避免形成历史断层。
- 接口缺少预期消息字段时明确失败，避免误报零消息成功。
- CSV 导出对公式开头的文字添加保护前缀；JSON 保留原文。

真实群消息能否读取、账号权限和平台限制，需登录后用目标群验证。界面启动与本地功能验证不等于已通过真实账号的长期采集验证。
